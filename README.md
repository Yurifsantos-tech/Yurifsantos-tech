## 🚀 Projeto em destaque — SentinelAI

### 🛡️ SentinelAI | Análise Defensiva de Eventos SSH

O **SentinelAI** é um projeto educacional desenvolvido em **Python**, voltado à análise defensiva de registros de eventos SSH.

### 🔍 Principais funcionalidades

- Leitura e processamento de arquivos **CSV**
- Análise de eventos de autenticação SSH
- Identificação de padrões temporais por regras
- Correlação de eventos por sessão
- Classificação de eventos para triagem
- Geração de relatórios explicativos
- Testes automatizados

**Estado do projeto:** MVP educacional, com documentação de limitações e validações funcionais. Não utiliza inteligência artificial nesta versão e não representa um sistema corporativo de detecção validado.

🔗 **Repositório:** [SentinelAI](https://github.com/Yurifsantos-tech/SentinelAI)
